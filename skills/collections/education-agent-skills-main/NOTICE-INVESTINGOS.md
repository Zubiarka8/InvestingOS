## Changes made by InvestingOS

1. **No skill text was edited.** On 2026-11-01 every one of the 279 upstream files kept here was compared by Git blob hash with the same path at the commit above; all matched.
2. **Files removed from this copy.** The upstream repository also contains software and generated files that the root notice does not clearly license: `mcp-server/` (a hosted MCP server; it carries its own CC BY-SA notice, but that was not reviewed for software use), `scripts/`, `tests/`, `requirements/`, `package.json`, `package-lock.json`, `playwright.config.ts`, `registry.json` (generated by `scripts/generate-registry.py`) and `assets/` (an icon). They were not deleted: they were moved to a local, git-ignored `local-only/` directory and are not part of the public package. Get them from the upstream repository.
3. **Broken upstream links.** Some retained documents (for example the README) link to the removed files. Those links do not resolve in this copy. The skills themselves do not depend on the removed files.
4. **Adaptations elsewhere in this project.** The Education section of [skills/INDEX.md](../../INDEX.md) reproduces skill names and descriptions from the metadata of these skills. Under the ShareAlike term, that section is also shared under CC BY-SA 4.0. The rest of InvestingOS keeps its own license.
