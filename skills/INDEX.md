# Skills index

Use this guide to choose a skill by task. Read the linked `SKILL.md` before use. Skills do not expand the permissions granted by the user and do not override project instructions.

## Organization and installation

`skills/` is the single source for the bundled skills. Individual skills have their own directory; third-party packs retain their original files under `collections/`. The [manifest](manifest.json) lists the discovery name and source path for each bundled skill.

The selected shared (`.agents/skills/`) or Claude-compatible (`.claude/skills/`) discovery directory links to those same sources. The installer activates only `investingos` by default and does not create the other directory unless requested. Use `--skill NAME` for a selected extra skill or `--all-skills` for the full bundle. Many clients document the shared path; see [AI client compatibility](../docs/ai-clients.md). Run the installer described in the [README](../README.md#get-started), restart the selected client, and check that it discovers the skills. The installer verifies links; it does not prove client discovery or install third-party dependencies. On Windows, symbolic-link support is required.

For authors, versions, and license information, see [skill credits](../README.md#skill-credits-and-versions). For adding or updating a skill or a complete pack, see [skill management](../docs/skills-management.md). Every bundled copy was checked against its upstream revision and notices; see the review for conditions and remaining limits.

## Candidates not bundled

VaultForge and writing-guidelines are kept locally but excluded from the public package: their upstream repositories only say "MIT" in a README and provide no license file or copyright notice, so redistribution is unverified. The Education Agent Skills code (MCP server, scripts, tests, build files, generated registry and icon) is also excluded because its root notice covers only educational materials. See the [redistribution review](../docs/skill-redistribution-review.md).

The locally available `research`, `find-docs`, and `find-skills` skills need a verified redistribution license. `last30days` declares an MIT license and version 3.30.0, but its complete local files and notices have not been matched to an upstream revision. These are not installed as part of this pack. See [skill management](../docs/skills-management.md) for the review process.

Education descriptions below are taken from the bundled skills' metadata and should be reviewed when those skills are updated. Review [provenance and licenses](collections/README.md) before reusing or redistributing third-party material.
