# Initial project evaluation

Public documentation was consulted on November 1, 2026. All five repositories were accessible through public pages. The GitHub API was unavailable from the environment at the time, so the latest commit date, recent activity, and complete dependency inventories were not verified; visible commit counts do not establish current maintenance. Four collections were subsequently copied into the project at the user's request; see [their provenance](../skills/collections/README.md).

| Project | Capabilities and decision | License and dependencies |
| --- | --- | --- |
| [Education Agent Skills](https://github.com/GarethManning/education-agent-skills) | Pedagogy and curriculum procedures; consult traceability and prerequisite ideas without adopting its agents into the core. | Educational materials are CC BY-SA; review LICENSE and specific dependencies. Includes packages and an MCP server. |
| [Course Builder](https://github.com/klausners/course-builder) | Research and course-generation plugin; consider its verification process in phase 2. | MIT; its documentation describes Claude Code and research tools. Dependency inventory pending. |
| [VaultForge](https://github.com/Easonnotsing/VaultForge) | Atomic notes, links, maps, and controversy analysis; consider navigation patterns. | Not bundled: its README states MIT but the repository has no license file or copyright notice. Pypdf is recommended for extraction, and deep research requires external tools. |
| [Obsidian Skills](https://github.com/kepano/obsidian-skills) | Guides for Markdown, Bases, Canvas, and CLI; useful adapter reference, not a core dependency. | MIT; some functions require Obsidian or its CLI; detailed inventory pending. |
| [ClassBuild](https://github.com/jtangen/classbuild) | Course generation and educational practices; review pedagogical design in phase 4. | MIT; JavaScript/TypeScript application with npm dependencies and AI services; detailed risk assessment pending. |

This evaluation is preliminary. Review the full license, dependencies, permissions, activity, and security for a specific version before further reuse or installation.
